# 中国是部金融史

## 一、总体核心逻辑

**财富循环的魔咒**：均田制/耕者有其田 → 经济井喷发展 → 封建官僚崛起 → 官商兼并土地 → 小农破产成为流民 → 帝国崩溃

**核心矛盾**：皇权需要借助封建官僚统治，但封建官僚本身就是强势分利集团，会利用权力疯狂掠夺财富。压力单向传导，小农承受最终代价。

## 二、各朝代财政大事件与影响

### 第一卷（周—唐）

| 朝代 | 核心财政/金融事件 | 财政后果 | 对各方影响 |
|------|-------------------|----------|-----------|
| **西周** | 封建制：以土地换忠诚；王德统治 | 王室土地逐渐被分割，经济基础弱化 | 诸侯崛起，王室衰微 |
| **春秋齐** | 管仲：官山海（盐铁专卖）、刀币、衡山之谋（货币战争） | 齐国富强称霸 | 国家垄断盐铁利；农民轻徭薄役 |

| **吕后（汉初）** | 《二年律令》：全国授田；十五税一（6.6%）；八铢钱→五分钱（货币贬值75%） | 国库空虚但农民有地；对外战争靠货币减资 | **耕者有其田**；小农稳定；诸侯被削弱 |

| **汉武帝** | 皮币/白金币/三铢钱（虚值货币）；算缗令、告缗令（告发富人）；盐铁官营；五铢钱统一 | 国库得民财以亿计；中产以上被扫空；流民涌入长安 | 官商崛起；土地兼并开始；农民失地 |

| **王莽新朝** | 宝货制（28种货币）；王田制（土地国有） | 掠夺黄金70万斤；超级通胀；经济瘫痪 | 得罪官僚+农民；流民起义；新朝灭亡 |
| **东汉光武** | 裁撤90%官僚；放任私铸货币；三十税一 | 光武中兴；陶瓷、造船、畜牧业爆发 | 坞堡经济兴起；军阀形成 |
| **东汉末** | 汉灵帝卖官；董卓无字小钱 | 超级通胀（粮百万钱/斛）；帝国信用崩溃 | 军阀混战；国家变土匪 |
| **曹操** | 屯田制（50%-60%税率）；《抑兼并令》；民间私铸五铢 | 粮食充盈；统一北方经济 | 流民变屯民；军阀被抑制 |
| **蜀汉** | 直百五铢、太平百钱（虚值货币） | 数月府库充实；经济崩溃 | 掠夺蜀地财富；百姓破产 |
| **西晋** | 占田制（70亩/丁）；无官方铸币 | 太康之治短暂；士族兼并土地 | 士族高门得利；农民失地；八王之乱 |
| **东晋** | 土断、开山泽之禁；沈郎钱（私铸） | 江南小农经济兴盛；纺织业衣被天下 | 士族衰败；寒门崛起 |
| **隋文帝** | 输籍法（百亩授田）；废盐铁专营；隋五铢（2.42克） | 开皇之治；全国农户翻倍（410万→890万）；粮仓堆积如山 | 耕者有其田；官僚不得经商 |
| **隋炀帝** | 白钱（锡合金）；国际贸易补贴；征高丽 | 北方经济崩溃；流民起义 | 关陇士族被打击；江南商人得利 |
| **唐初（贞观）** | 按官职授田（非全民）；公廨钱（官营高利贷） | 民户仅300万（隋800万）；府库空虚 | 封建官僚得土地；农民负担重 |
| **武则天** | 乾封通宝（虚值货币）；告密令；酷吏统治 | 天下户口几亡其半；流民遍地 | 关陇士族被清洗；寒门酷吏得势 |
| **唐玄宗开元** | 裁撤官营手工业；放开私铸；开元限购令（禁土地买卖） | 开元盛世；纺织业巅峰；粮价稳定 | 小农得土地；封建官僚被抑制 |
| **天宝年间** | 杨国忠：放开土地买卖；大盈库（皇帝私库） | 40%农民失地；流民遍地；朱门酒肉臭 | 官商得利；安史之乱爆发 |
| **安史之乱后** | 乾元重宝（虚值货币）；盐铁专卖重启；两税法（向富人征税） | 盐税占收入80%；物价暴涨；钱荒 | 封建官僚转嫁税负；小农更苦 |

## 三、关键财政制度演变

| 制度 | 首创/推行者 | 核心内容 | 财政效果 | 副作用 |
|------|------------|----------|----------|--------|
| **盐铁专卖** | 管仲/汉武帝 | 国家垄断盐铁生产销售 | 快速增加财政收入 | 官商垄断，民间经济窒息 |
| **均田制** | 吕后/隋文帝/唐太宗 | 按丁授田（百亩） | 耕者有其田，经济复苏 | 土地兼并难以根治 |
| **屯田制** | 曹操 | 流民耕种官田，分成50%-60% | 解决军粮，恢复生产 | 税率高，屯民负担重 |
| **两税法** | 杨炎（唐） | 按资产征税，收货币 | 向富人征税 | 封建官僚转嫁税负 |
| **青苗法** | 王安石 | 官府放高利贷（40%-300%年息） | 财政收入暴增 | 农民破产，流民增加 |
| **一条鞭法** | 张居正（明） | 赋役合并，统一征银 | 简化税制，减少盘剥 | 白银依赖海外，农民无银缴税 |

## 四、财政困境的根源（贯穿全书）

1. **封建官僚是强势分利集团**：他们利用权力垄断赚钱行业、兼并土地，最终吸干帝国财富
2. **土地兼并无法根治**：无论限购令、均田制、王田制，最终都被封建官僚规避
3. **货币被用作抢劫工具**：虚值货币、通货膨胀、通货紧缩，最终都让穷人更穷
4. **流民是帝国崩溃的前兆**：当小农失去土地→成为流民→揭竿而起→帝国灭亡
5. **皇帝与封建官僚的矛盾**：皇权需要官僚统治，但官僚会反噬皇权

## 七、核心启示

> **“天下之财，止有此数，不在民，则在官！”** —— 司马光

- 财富不会凭空产生，官府多拿一分，百姓就少一分
- 任何以“理财”为名的聚敛，本质都是抢劫
- 盛世的关键：让民间有钱、让创新自由、让封建官僚不能肆意掠夺
- 衰败的征兆：官商崛起、土地兼并、流民出现、货币信誉崩溃
