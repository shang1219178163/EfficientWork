# AI名词

Agent 就是能干活的全能AI员工。
Openclaw 就是住在你电脑里面的AI管家。
Skills 就是 Agent 的功能秘籍。
MCP 就是 AI 连接工具的万能接口。
抽卡 就是 AI 生成内容的随机盲盒体验。
API 就是连接万物的万能插座。
多模态 就是 AI 的全感官能力。
RAG（Retrieval-Augmented Generation，检索增强生成） 就是企业的AI外挂大脑。
AIGC 就是AI创作的内容统称。
TOKEN 就是AI世界的货币单位。
Vibe coding 沉浸式编程，说白了就是，人类负责出题+审核，AI 负责解题+改卷，全过程都沉浸在“即时反馈→调整→再反馈→再调整”的闭环里。


## Claude

Opus（杰作/巨著）：旗舰级王牌。性能最强、推理能力最深，适合处理极其复杂的分析、数学和创造性任务。但速度最慢、成本最高。

Sonnet（十四行诗）：中坚力量。在智能水平和速度之间取得了最佳平衡，性价比极高。适合大多数日常办公、编程和文本处理任务，是目前应用最广泛的模型。

Haiku（俳句）：轻量快枪手。体积最小、速度最快、成本极低，适合需要快速响应的实时任务（如客服、内容分类）。

Fable（寓言）：这个比较特殊。它不是当前Claude 3/4系列中的一员，而是Claude 2时代的早期内部代号或指代旧版模型。现在Anthropic已不再使用Fable作为正式产品名，它更多被视作“前辈”或“传说级”的试水作品。
