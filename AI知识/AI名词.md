# AI名词

Agent 就是能干活的全能AI员工。
Openclaw 就是住在你电脑里面的AI管家。
Skills 就是 Agent 的功能秘籍。
MCP 就是 AI 连接工具的万能接口。
抽卡 就是 AI 生成内容的随机盲盒体验。
API 就是连接万物的万能插座。
多模态 就是 AI 的全感官能力。
RAG（Retrieval-Augmented Generation，检索增强生成） 就是企业的AI外挂大脑。
AIGC 就是AI创作的内容统称。
TOKEN 就是AI世界的货币单位。
Vibe coding 沉浸式编程，说白了就是，人类负责出题+审核，AI 负责解题+改卷，全过程都沉浸在“即时反馈→调整→再反馈→再调整”的闭环里。
